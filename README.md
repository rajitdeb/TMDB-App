## How to get started with the repo ?
1. Clone the repo. <br >
2. Then go to [this][2] link and register for an API Key. <br >
3. Go to `constants.dart` under `utils` folder in the `lib` directory. <br >
4. Paste your api key in the `YOUR_API_KEY` field.
